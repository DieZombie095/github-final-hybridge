# Tech Solutions Inc. — Monitoreo del servidor

Entregables del proyecto de monitoreo y optimización de Ubuntu Server.

- Reporte: `Reporte_Monitoreo_Sistema.pdf`
- Script: `monitoreo_sistema.sh`
- Configuración de Cron: `crontab_root.txt`
- Ajuste de memoria: `99-tech-solutions-memory.conf`
- Referencia de swap: `fstab_swap_referencia.txt`
- Ejemplo de formato de log: `monitoreo_sistema.log.ejemplo`

Consulta el reporte para los pasos de instalación, validación y evidencia requerida. El archivo de log de ejemplo está identificado como ilustrativo; las mediciones reales se generan en el servidor al ejecutar el script.
